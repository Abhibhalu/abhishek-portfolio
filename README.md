# Abhishek | DevOps Engineer Portfolio

A modern, responsive and animated personal portfolio website
built using HTML, CSS and JavaScript.

The portfolio highlights my interest and practical learning
in AWS Cloud, DevOps engineering, CI/CD automation,
containerization and Infrastructure as Code.

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- AWS
- Docker
- Kubernetes
- Jenkins
- Terraform
- Git and GitHub

---

## Website Features

- Modern dark-themed interface
- Animated 3D cube
- Floating technology elements
- Animated background particles
- Responsive navigation
- Scroll reveal animations
- Responsive project cards
- Technical skills section
- Practical experience section
- Contact section
